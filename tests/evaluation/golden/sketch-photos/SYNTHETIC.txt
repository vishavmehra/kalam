SYNTHETIC: THESE ARE NOT REAL PHOTOS OF REAL DRAWINGS
=====================================================

Every image in this folder was generated by an AI image model. Nobody drew these sketches on paper and
nobody photographed them. They stand in for the 25 hand-drawn photos that .handoff/eval-sketch-guide.txt
asks the owner to take, so the photo route of the evaluation can run before real photos exist.
Replace each file with the real photo of the same name when it exists (same file name, .jpg or .png).

How they were made
  Firebase AI Logic only (Firebase JS SDK firebase/ai, Agent Platform Gemini API backend, App Check debug token).
  First attempt: gemini-nano-banana-2.1. A second attempt with gemini-3-pro-image was made only when more than
  one required label could not be read back (rule below). Generated 2026-11-25.
  Prompt: a phone photo of a hand-drawn app sketch on white A4 paper, pen type and light varied per case, the
  screens and labels taken from tests/evaluation/golden/sketches.json, drawn with the guide's shapes.
  All labels in these cases are English or Hinglish-in-English-letters, so no case needed its Hindi swapped
  for English. Hindi was never asked of the model.
  Each JPEG also carries a SYNTHETIC notice in its EXIF ImageDescription.

Legibility check (one Firebase AI vision call per image, model gemini-3.8-flash)
  The model reads the handwriting blind (it is not told the labels). A required label counts as readable when
  at least 70% of its words appear in the transcription with fuzzy matching. More than one unreadable label
  triggers one regeneration; the attempt with fewer unreadable labels is kept.
  This proves a model can read the labels. It does not prove the sheet looks like a real person's drawing:
  these sketches are cleaner and more uniform than real ones, so they are an easier test.
