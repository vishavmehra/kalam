What is generated and what is code
  paper-*, cloth-*, stamp-*  : generated by the model, then cropped, resized and converted to webp (Pillow).
  stamp-*                    : additionally turned into an alpha cut-out in code (ink density becomes opacity).
  hero-sketch-tailor*.webp   : a COMPOSITE. The paper is paper-cream (generated). The Hindi handwriting, the
                               red "No. 0417", the boxes and the button are set in code: Kalam font from Google
                               Fonts (OFL), SVG with seeded jitter and an ink filter, rendered with the installed
                               Playwright Chromium at 2x. The model was never asked to write Hindi.
  hero-sketch-tailor.fields.json : where each field sits on the hero (fractions of the image).
